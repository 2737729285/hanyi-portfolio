# 韩易 HAN YI — AI Film Director Portfolio

纯 HTML + CSS + JavaScript 单页作品集，无构建步骤，可直接部署到 GitHub Pages。

## 使用方式

1. 在浏览器中打开 `index.html` 即可预览。
2. 将 `outputs` 目录中的全部文件上传到 GitHub 仓库根目录。
3. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，再选择 `main` / `(root)`。

## 当前内容结构

作品素材按类型整理：

- `images/`：Hero 封面、项目封面和账号图片；高体积图片已转换为 WebP。
- `audio/`：音乐作品。
- 根目录 MP4：当前网页使用的视频文件。

首页和项目 02 共用《狠三国》的 13 秒视觉片段，避免重复存储。项目 01 和项目 03 已转为浏览器兼容的 H.264 MP4，原始文件没有被修改。

后续增加项目时，在 `VIDEO PROJECTS` 或 `AUDIO PROJECTS` 分类中复制对应项目结构，然后替换封面、媒体、标题、职责、制作过程和成果即可。个人工作流位于 About 模块中统一展示。

建议视频使用 H.264 编码的 MP4，并控制在 10–20 MB 以内；GitHub Pages 对大型视频不够友好，正式项目可将视频托管到腾讯云 COS、阿里云 OSS 或其他对象存储。

当前项目视频采用按需加载：页面初次打开只显示封面，用户点击播放后才为弹窗播放器设置 MP4 地址；关闭弹窗后会释放视频资源。新增项目时请继续使用 `data-video`，不要在项目卡片中直接放置带 `src` 的 `<video>`。
